# Архитектура backend

Рабочий поток намеренно короткий:

`JSON/CSV → FastAPI → локальный parser → плоский JSON`.

- `app/api/routes/challenge.py` принимает один адрес, массив или файл;
- `app/parser/challenge.py` разбирает строку без сетевых запросов;
- `app/schemas/challenge.py` фиксирует контракт задания;
- `address_references` предназначена для последующего уточнения найденных
  области, города, района, жилого массива и улицы;
- Alembic создаёт и обновляет таблицу справочника в PostgreSQL.

Основной batch-метод не зависит от наличия данных в справочнике: каждая входная
строка всегда возвращается в результате.
