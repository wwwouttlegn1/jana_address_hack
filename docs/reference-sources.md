# Справочники адресов

Основные типы таблицы `address_references`: `province`, `city`, `district`,
`living_area`, `street`. Для совместимости импорт также понимает `country`,
`region` и `settlement`. Каждая запись может содержать внешний `code`,
`parent_id` и произвольные атрибуты источника.

Для production следует загружать официальные адресные данные с сохранением кода
и источника в `attributes`. Импорт должен выполняться идемпотентно по комбинации
`kind + normalized_name + parent_id`; удаление справочника при обновлении не
требуется — устаревшую запись можно пометить `enabled=false`.
